Etiquetas cortas: estado de turno, categoría de especialidad, filtros.

```jsx
<Badge tone="success" dot>Confirmado</Badge>
<Badge tone="sand">Adolescentes</Badge>
<Tag>Terapia individual</Tag>
```

`success`/`error` para estado; `forest`/`soft`/`sand` para categorías de marca; `outline` para neutro. `Tag` es un chip interactivo (hover cambia borde/color) para filtros clicables.
