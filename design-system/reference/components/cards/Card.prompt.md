Contenedor de contenido: especialidades, equipo, testimonios.

```jsx
<Card variant="spec" icon={<LeafIcon/>} title="Terapia individual" description="Un espacio propio para explorar y crecer." hoverable/>
<Card variant="team" media={<img src="foto.jpg"/>} title="Lic. Ana Gómez" role="Psicóloga clínica" meta="Mat. 12345"/>
<Card variant="quote" quote="Encontré un espacio de calma real." author="M.F." authorMeta="Paciente desde 2023"/>
```

`quote` usa fondo slate sólido — reservar para 1 por sección. `hoverable` eleva la card 4px al pasar el mouse.
